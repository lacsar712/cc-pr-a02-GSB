# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，按领取瞬间记下的允差算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

青品允差（毫米）由印刷员在侧栏「青品允差档」维护：独立领取进程领走任务时读取此刻的现行允差，青、品偏差的绝对值都不大于允差才写“套准”，否则写“套不准”，并把该档快照记在任务上。正在领取中的任务继续沿用领取瞬间记下的允差，改档只影响尚未领取的新队。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可维护允差档 |
| checker | check123456 | 只看：可见任务、结论与允差档，不能改档，也不能送复核 |

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮，侧栏没有改档表单，但看得见现行允差与最近改档记录。
4. 允差改档只影响后续领取：
   1. 在侧栏把允差改成 0.10 毫米；
   2. 送一条青偏差 0.12、品 0.02 的插页，最终应**套不准**（任务上记下的允差为 0.10）；
   3. 把允差调回 0.15 毫米，再送同样青 0.12、品 0.02 的插页，最终应**套准**（任务上记下的允差为 0.15）；
   4. 侧栏「最近改档记录」能看到每次改档的毫米值、操作人与时间。
