# 印刷套准复核台

接口把印张偏差放进待处理队列。另一个进程用行锁领走一条：领取的瞬间读取此刻的青品允差并记在该任务上，青、品两色偏差绝对值都不大于记下的允差才写“套准”，否则写“套不准”，再写回。页面每隔一秒看一次，直到结论出现。

允差（毫米）改由印刷员在「允差档」页维护，带改档记录。改档只作用于改档之后被领取的新队；正在领取中或已有结论的任务继续用领取瞬间记下的旧档，结论不变。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可改允差档 |
| checker | check123456 | 只看：可见允差与结论，不能改档，也不能送队 |

## 启动

```bash
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准（默认允差 0.15 毫米）。
2. 侧栏进入「允差档」，把允差改成 0.1；再送一条青偏差 0.12、品 0.02 的插页，最终应是**套不准**。
3. 把允差调回 0.15，再送同样青偏差 0.12 的插页，最终应是**套准**。
4. 改档记录页能看到每次改档的毫米数、改档人与时间；队列总表里没有允差列。
5. checker 登录：看得到允差与结论，没有送复核和改档入口，直接调接口也会被拒（403）。
